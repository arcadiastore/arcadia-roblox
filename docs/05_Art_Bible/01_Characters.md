# Karakter (Art Bible)

## Ringkasan

Panduan visual untuk desain karakter.

## Gaya Karakter

### Prinsip
- **Anime Cel-Shaded** — Garis tebal, warna datar dengan shading
- **Proporsi** — 7-8 kepala (semi-realistic anime)
- **Ekspresi** — Besar dan jelas, mirip anime Jepang
- **Siluet** — Setiap karakter harus bisa dikenali dari siluet

### Warna Karakter
- Setiap karakter memiliki 3 warna utama
- Warna mencerminkan personality
- Kontras tinggi antara karakter

## Player Character

### Warrior
- **Warna:** Merah, hitam, silver
- **Ciri:** Armor tebal, pedang besar, shield
- **Rambut:** Pendek, gelap
- **Ekspresi:** Tegas, berani

### Mage
- **Warna:** Biru, ungu, putih
- **Ciri:** Robe panjang, staff, orb
- **Rambut:** Panjang, berkilau
- **Ekspresi:** Cerdas, tenang

### Archer
- **Warna:** Hijau, coklat, emas
- **Ciri:** Light armor, bow, quiver
- **Rambut:** Sedang, diikat
- **Ekspresi:** Lincah, waspada
