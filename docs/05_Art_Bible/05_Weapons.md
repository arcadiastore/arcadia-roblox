# Senjata (Art Bible)

## Ringkasan

Panduan visual untuk desain senjata.

## Kategori Senjata

### Sword (Pedang)
- **Tipe:** 1H Sword, 2H Sword
- **Gaya:** Medieval, anime
- **Warna:** Silver blade, sesuai rarity
- **Detail:** Engraving, gem slot

### Axe (Kapak)
- **Tipe:** 1H Axe, 2H Axe
- **Gaya:** Viking, dwarf
- **Warna:** Silver blade, wood handle
- **Detail:** Rune carving

### Hammer (Palu)
- **Tipe:** 1H Hammer, 2H Hammer
- **Gaya:** Dwarf, heavy
- **Warna:** Silver head, wood handle
- **Detail:** Gem slot, rune

### Staff (Tongkat)
- **Tipe:** Staff, Wand
- **Gaya:** Wizard, magical
- **Warna:** Wood, crystal, gem
- **Detail:** Orb di ujung, rune

### Bow (Busur)
- **Tipe:** Short Bow, Long Bow
- **Gaya:** Elf, ranger
- **Warna:** Wood, string
- **Detail:** Engraving, gem

### Dagger (Belati)
- **Tipe:** Dagger, Dual Dagger
- **Gaya:** Assassin, rogue
- **Warna:** Silver blade, dark handle
- **Detail:** Poison slot, shadow effect

## Rarity Visual

| Rarity | Efek Visual |
|--------|------------|
| Common | Biasa, tanpa efek |
| Uncommon | Sedikit bercahaya |
| Rare | Bercahaya terang |
| Epic | Partikel bercahaya |
| Legendary | Aura khusus, partikel |

## Set Weapon

Set weapons memiliki tema visual yang sama:
- **Dragon Slayer Set:** Pedang dengan sisik naga
- **Forest Guardian Set:** Senjata dari kayu dan kristal
- **Demon King Set:** Senjata dari api dan kegelapan
