# UI (Art Bible)

## Ringkasan

Panduan desain antarmuka pengguna.

## Gaya UI

### Prinsip
- **Clean** — Bersih, tidak ramai
- **Consisten** — Gaya sama di semua menu
- **Readable** — Mudah dibaca
- **Anime** — Terinspirasi anime/UI game Jepang

### Warna UI
| Elemen | Warna |
|--------|-------|
| Background | Dark semi-transparent |
| Text | White, Yellow (highlight)
| Border | Gold, Silver |
| Button | Gradient, glow on hover |
| HP Bar | Red → Green |
| MP Bar | Blue |
| EXP Bar | Yellow |

## Font

| Fungsi | Font | Ukuran |
|--------|------|--------|
| Title | Bold, stylized | 32-48px |
| Heading | Bold | 24-32px |
| Body | Regular | 16-20px |
| Caption | Light | 12-14px |

## Button Style

### Primary Button
- Background: Gradient (gold → dark gold)
- Border: 2px gold
- Text: White, bold
- Hover: Glow effect
- Press: Scale down

### Secondary Button
- Background: Gradient (grey → dark grey)
- Border: 2px silver
- Text: White
- Hover: Lighter grey
- Press: Scale down

## Notifikasi

| Tipe | Warna | Durasi |
|------|-------|--------|
| Info | Biru | 3s |
| Warning | Kuning | 3s |
| Error | Merah | 3s |
| Achievement | Emas | 5s |
| Level Up | Emas | 3s |

## UI Animation

| Aksi | Animasi |
|------|--------|
| Open | Fade in + scale |
| Close | Fade out + scale |
| Tab switch | Slide |
| Button hover | Glow + scale |
| Notification | Slide in + fade out |

## Mobile UI

- **Touch target:** Min 48x48px
- **Spacing:** Min 8px antar elemen
- **Font:** Min 16px untuk readability
- **Button:** Besar, mudah ditekan
