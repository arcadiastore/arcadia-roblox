# NPC (Art Bible)

## Ringkasan

Panduan visual untuk desain NPC.

## NPC Categories

### Merchant NPC
- **Ciri:** Tas besar, timbangan, koin
- **Warna:** Emas, coklat, hijau
- **Ekspresi:** Ramah, serakah
- **Contoh:** Blacksmith Tom, Merchant Guild

### Quest Giver NPC
- **Ciri:** Simbol "!" di atas kepala
- **Warna:** Bervariasi
- **Ekspresi:** Urgent, memohon
- **Contoh:** Tetua Aldric, Captain Rod

### Lore NPC
- **Ciri:** Pakaian sehari-hari
- **Warna:** Netral, earth tone
- **Ekspresi:** Tenang, informatif
- **Contoh:** Penjaja cerita, sejarawan

### Guard NPC
- **Ciri:** Armor seragam, senjata
- **Warna:** Silver, biru, merah
- **Ekspresi:** Tegas, waspada
- **Contoh:** City Guard, Royal Guard

### Companion NPC
- **Ciri:** Unik, signature design
- **Warna:** Bervariasi per karakter
- **Ekspresi:** Ekspresif, memorable
- **Contoh:** Lyra, Borin, Elara, Shadow

## Companion Visual Design

### Lyra (Mage)
- **Warna:** Biru muda, putih, silver
- **Rambut:** Panjang, biru, berkilau
- **Mata:** Biru besar
- **Pakaian:** Robe mage, buku sihir
- **Signature:** Orb biru mengambang

### Borin (Warrior)
- **Warna:** Coklat, merah, silver
- **Rambut:** Pendek, merah, brewok
- **Mata:** Hijau
- **Pakaian:** Armor dwarf, palu
- **Signature:** Palu besar di punggung

### Elara (Healer)
- **Warna:** Putih, emas, pink
- **Rambut:** Pendek, pirang
- **Mata:** Hijau lembut
- **Pakaian:** Robe healer, tongkat
- **Signature:** Halo kecil di atas kepala

### Shadow (Assassin)
- **Warna:** Hitam, ungu, silver
- **Rambut:** Sedang, hitam, menutupi mata
- **Mata:** Satu terlihat (merah)
- **Pakaian:** Armor ringan, jubah
- **Signature:** Belati ganda

## NPC Animation

| Animasi | Fungsi |
|---------|--------|
| Idle | Berdiri diam |
| Talk | Bergerak saat bicara |
| Gesture | Menunjuk, melambaikan |
| Walk | Berjalan sesuai schedule |
| Work | Aktivitas (menempa, memasak) |

## NPC Icon

- Simbol "?" untuk quest tersedia
- Simbol "!" untuk quest aktif
- Simbol pedang untuk merchant
- Simbol hati untuk companion

## NPC Placement

- Merchant: di dalam toko
- Quest Giver: di area strategis
- Guard: di pintu masuk
- Companion: di lokasi rekrutmen
