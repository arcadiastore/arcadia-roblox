## Color Accessibility

### Colorblind Modes
| Mode | Change |
|------|--------|
| Protanopia | Red → Orange |
| Deuteranopia | Green → Blue |
| Tritanopia | Blue → Purple |

### Contrast Ratios
- Text on background: Min 4.5:1
- Large text: Min 3:1
- UI elements: Min 3:1

## Color Usage Rules

1. **Konsisten** — Warna yang sama untuk fungsi yang sama
2. **Kontras** — Pastikan text terbaca
3. **Bermakna** — Warna harus punya makna
4. **Aksesibel** — Support colorblind
5. **Performance** — Hindari terlalu banyak warna berbeda
