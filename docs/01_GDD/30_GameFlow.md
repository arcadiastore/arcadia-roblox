# 30 — Alur Game (Game Flow)

## Ringkasan

Alur game menggambarkan pengalaman pemain dari awal hingga akhir. Ini adalah panduan untuk memastikan konten disampaikan dengan ritme yang tepat.

## Alur Utama

### Act 1: Permulaan (Lv 1-25)
```
1. Pembuatan Karakter
2. Tutorial: Movement, Combat, UI
3. Beginner Village: Quest dasar
4. Pertama kali pertarungan
5. Rekrut companion pertama
6. Quest utama: "Permintaan Tetua"
7. Green Forest: Eksplorasi pertama
8. Boss pertama: Guardian of the Forest
9. Sage Tower: Unlock magic system
```

### Act 2: Konflik (Lv 25-55)
```
10. Sage Tower: Puzzle & lore
11. Rebel HQ: Faction conflict
12. Pilihan moral pertama
13. War Battle #1
14. Capital City: Political intrigue
15. Companion quest chains
16. Job advancement (Tier 2)
17. Dark Caverns: Undead threat
```

### Act 3: Klimaks (Lv 55-85)
```
18. Capital City: Siege event
19. Pilihan moral kritis
20. WorldState berubah drastis
21. Job advancement (Tier 3)
22. Dark Caverns: Demon awakening
23. Companion loyalty test
24. War Battle #2
25. Demon King reveal
```

### Act 4: Resolusi (Lv 85-100)
```
26. Sky Islands: Final preparation
27. All companion recruitment
28. Final dungeon: Demon Castle
29. Final boss: Demon King
30. Ending berdasarkan pilihan
31. Credit & epilogue
32. Post-game content
```

## Ritme Konten

| Aktivitas | Frekuensi |
|-----------|-----------|
| Dialog & cerita | Setiap 10-15 menit |
| Pertarungan | Setiap 5-10 menit |
| Eksplorasi | Setiap 15-20 menit |
| Cutscene | Setiap 30-60 menit |
| Boss | Setiap 1-2 jam |

## Pacing

### Pendekatan "Breath"
```
Tension (Pertarungan) → Release (Dialog) → Tension (Eksplorasi) → Release (Cutscene)
```

### Contoh Sesi 1 Jam
```
00:00 - 00:10: Eksplorasi area baru
00:10 - 00:20: Pertarungan dengan monster
00:20 - 00:30: Dialog dengan NPC
00:30 - 00:40: Quest objective
00:40 - 00:50: Boss pertarungan
00:50 - 01:00: Cutscene & reward
```

## Tutorial Flow

### Mandatory Tutorial
1. Movement (WASD + mouse)
2. Camera control
3. Basic attack
4. Skill usage
5. Item usage
6. Menu navigation

### Optional Tutorial
- Advanced combat
- Crafting
- Pet system
- Mount system
- PvP (MMORPG)
