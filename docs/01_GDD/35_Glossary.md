# 35 — Glosarium

## Ringkasan

Glosarium berisi daftar istilah yang digunakan dalam dokumentasi dan game Arcadia Online.

## Istilah Game

| Istilah | Definisi |
|---------|----------|
| **AoE** | Area of Effect — Skill yang memengaruhi area |
| **ATK** | Attack — Stat serangan fisik |
| **Auto Hunt** | Mode berburu otomatis |
| **Auto Path** | Mode bergerak otomatis ke tujuan |
| **BGM** | Background Music — Musik latar |
| **Boss** | Monster kuat di akhir dungeon |
| **Buff** | Efek positif sementara |
| **CC** | Crowd Control — Efek kontrol (stun, slow) |
| **CD** | Cooldown — Waktu tunggu skill |
| **CD** | Critical Damage — Damage kritis |
| **CR** | Critical Rate — Peluang kritis |
| **Debuff** | Efek negatif sementara |
| **DEF** | Defense — Stat pertahanan |
| **DOT** | Damage Over Time — Damage bertahap |
| **DPS** | Damage Per Second — Damage per detik |
| **Dungeon** | Area khusus dengan monster & boss |
| **EXP** | Experience — Poin pengalaman |
| **EVA** | Evasion — Peluang menghindar |
| **Faction** | Kelompok/faksi dalam game |
| **GDD** | Game Design Document |
| **HP** | Health Points — Nyawa karakter |
| **HUD** | Heads-Up Display — Tampilan di layar |
| **I-frame** | Invincibility Frame — Frame kebal |
| **KO** | Knock Out — Karakter pingsan |
| **LUK** | Luck — Stat keberuntungan |
| **MATK** | Magic Attack — Stat serangan magic |
| **MDEF** | Magic Defense — Stat pertahanan magic |
| **MMORPG** | Massively Multiplayer Online RPG |
| **MP** | Magic Points — Mana |
| **NPC** | Non-Player Character |
| **Pet** | Makhluk peliharaan |
| **PvE** | Player vs Environment |
| **PvP** | Player vs Player |
| **Quest** | Misi/tugas dalam game |
| **RMT** | Real Money Trading |
| **SFX** | Sound Effects — Efek suara |
| **SPD** | Speed — Stat kecepatan |
| **Tank** | Karakter dengan HP/DEF tinggi |
| **Ultimate** | Skill terkuat dengan cooldown panjang |
| **WorldState** | Status/kondisi dunia game |
| **XP** | Sama dengan EXP |

## Istilah Teknis

| Istilah | Definisi |
|---------|----------|
| **URP** | Universal Render Pipeline (Unity) |
| **Cel-Shaded** | Gaya rendering seperti kartun |
| **LOD** | Level of Detail — Detail berdasarkan jarak |
| **FPS** | Frames Per Second |
| **API** | Application Programming Interface |
| **SDK** | Software Development Kit |
| **Asset** | Resource game (model, texture, audio) |
| **Build** | Versi game yang sudah di-compile |
| **Patch** | Update/perbaikan game |
| **Hotfix** | Perbaikan darurat |
