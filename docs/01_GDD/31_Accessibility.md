# 31 — Aksesibilitas

## Ringkasan

Arcadia Online berkomitmen untuk dapat dinikmati oleh semua pemain, termasuk mereka yang memiliki keterbatasan. Fitur aksesibilitas dirancang untuk tidak mengurangi pengalaman bermain.

## Fitur Aksesibilitas

### Visual

| Fitur | Deskripsi |
|-------|-----------|
| **Colorblind Mode** | Protanopia, Deuteranopia, Tritanopia |
| **Ukuran Font** | Small, Medium, Large, Extra Large |
| **Kontras** | Low, Normal, High |
| **UI Scale** | 75% - 150% |
| **Subtitle** | Ukuran & warna bisa diatur |
| **Screen Reader** | Support untuk teks di layar |

### Audio

| Fitur | Deskripsi |
|-------|-----------|
| **Subtitle** | Teks untuk semua dialog |
| **Visual Cue** | Indikator visual untuk suara penting |
| **Volume Control** | Per kategori (BGM, SFX, Voice) |
| **Mono Audio** | Untuk pemain dengan gangguan pendengaran satu sisi |

### Kontrol

| Fitur | Deskripsi |
|-------|-----------|
| **Remappable Controls** | Semua tombol bisa di-remap |
| **One-Hand Mode** | Layout untuk satu tangan |
| **Auto-Aim** | Targeting otomatis |
| **Auto-Combo** | Combo otomatis |
| **Hold vs Toggle** | Pilihan hold atau toggle untuk aksi |

### Gameplay

| Fitur | Deskripsi |
|-------|-----------|
| **Difficulty Settings** | Easy, Normal, Hard |
| **Auto Save** | Frekuensi bisa diatur |
| **Pause** | Bisa pause kapan saja |
| **Skip Cutscene** | Bisa skip semua cutscene |
| **Tutorial Skip** | Bisa skip tutorial |

## Difficulty Settings

| Setting | Easy | Normal | Hard |
|---------|------|--------|------|
| Enemy HP | 50% | 100% | 150% |
| Enemy ATK | 50% | 100% | 150% |
| EXP Gain | 150% | 100% | 75% |
| Gold Gain | 150% | 100% | 75% |
| Auto Save | Every 2 min | Every 5 min | Every 10 min |
| Death Penalty | None | Minor | Harsh |

## Testing

- Playtesting dengan pemain berkebutuhan khusus
- Konsultan aksesibilitas
- Compliance dengan WCAG 2.1 (adaptasi untuk game)
