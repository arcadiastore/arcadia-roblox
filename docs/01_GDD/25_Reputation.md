# 25 — Sistem Reputasi

## Ringkasan

Sistem reputasi melacak hubungan pemain dengan berbagai faction di dunia Arcadia. Reputasi memengaruhi akses konten, harga toko, dan ending.

## Faction

| Faction | Deskripsi | Lokasi |
|---------|-----------|--------|
| **Royal Guard** | Pasukan kerajaan | Capital City |
| **Merchant Guild** | Guild pedagang | Semua kota |
| **Rebel Army** | Pemberontak | Rebel HQ |
| **Mage Circle** | Penyihir | Sage Tower |
| **Thieves Guild** | Pencuri | Shadow District |
| **Demon Faction** | Pengikut iblis | Dark Caverns |

## Level Reputasi

## Cara Meningkatkan Reputasi

| Aksi | Contoh |
|------|--------|
| Quest | Selesaikan quest faction |
| Dialog | Pilihan positif dalam dialog |
| Donasi | Donasi gold ke faction |
| Pertolongan | Bantu anggota faction |

## Cara Menurunkan Reputasi

| Aksi | Contoh |
|------|--------|
| Quest | Gagal quest faction |
| Dialog | Pilihan negatif |
| Kejahatan | Mencuri, membunuh NPC faction |
| Musuh | Membantu musuh faction |

## Efek Reputasi

### Toko
- **Friendly:** Diskon 10%
- **Honored:** Diskon 20% + item eksklusif
- **Revered:** Diskon 30% + item legendary

### Quest
- **Friendly:** Quest sampingan tersedia
- **Honored:** Quest chain tersedia
- **Revered:** Quest rahasia tersedia

### Area
- **Hostile:** Tidak bisa masuk area faction
- **Neutral:** Akses terbatas
- **Friendly:** Akses penuh

### Ending
- Reputasi memengaruhi ending
- Faction tertentu memerlukan level minimum
- Multiple endings berdasarkan reputasi

## Conflict System

Faction bisa saling bertentangan:
- Royal Guard vs Rebel Army
- Merchant Guild vs Thieves Guild
- Mage Circle vs Demon Faction

Meningkatkan reputasi di satu faction bisa menurunkan di faction lawan.
