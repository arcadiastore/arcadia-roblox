# 26 — Antarmuka Pengguna (UI)

## Ringkasan

UI Arcadia Online dirancang untuk bersih, informatif, dan tidak mengganggu pengalaman bermain. Gaya visual mengikuti tema anime cel-shaded.

## Prinsip Desain UI

1. **Minimalis** — Hanya tampilkan informasi penting
2. **Konsisten** — Gaya yang sama di semua menu
3. **Responsif** — Respon cepat terhadap input
4. **Aksesibel** — Ukuran font yang bisa diubah, colorblind support

## HUD (Heads-Up Display)

```
┌─────────────────────────────────────────────┐
│ [HP Bar] [MP Bar]              [Minimap]    │

│                                              │

│ [Quick Slot 1-4]    [Skill Bar 1-8]         │

```

### Komponen HUD
| Komponen | Fungsi |
|----------|--------|
| HP Bar | Nyawa karakter |
| MP Bar | Mana karakter |
| Level | Level karakter |
| EXP Bar | Progress EXP |
| Minimap | Peta kecil |
| Quest Tracker | Quest aktif |
| Quick Slot | Item cepat |
| Skill Bar | Skill yang di-equip |
